## 2025-01-20 - DOM Element Caching in Vanilla JS Clickers\n**Learning:** In vanilla JS clicker games without frameworks, rapidly executing `click` handlers and `setInterval` loops often continuously poll the DOM via `document.getElementById` and `querySelector`. This can severely bottleneck performance due to main-thread blocking and layout thrashing overhead.\n**Action:** Always extract and cache static DOM elements referenced in fast-firing loops or rapid event handlers into a structured `cachedDOM` object to prevent redundant API queries.
