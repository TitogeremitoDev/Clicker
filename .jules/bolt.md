## 2024-07-24 - DOM Query Caching in Clicker Games
**Learning:** In clicker/incremental games, the hot paths for the event loop are incredibly frequent (clicks per second, interval ticks). Re-querying the DOM using `document.getElementById` or `document.querySelector` inside the click handlers or frequent interval loops causes significant performance drag because of repeated DOM tree traversal.
**Action:** Always extract and cache these DOM elements to higher-scoped constants/variables during the initial load so the hot path event handlers only perform property updates on the already-cached node references. Also utilize `{ once: true }` in `addEventListener` for handlers like starting background audio when the user first interacts with the page, avoiding pointless listener invocation on every subsequent interaction.
