## 2024-05-18 - [DOM Query Overhead in High-Frequency Game Loops]
**Learning:** In vanilla JavaScript game development, high-frequency loops (like `dañocontinuo` running every 500ms via `setInterval`) can suffer from performance degradation due to redundant DOM queries (e.g., `document.getElementById`). While synthetic benchmarks may show negligible differences, caching these elements at the top level is a critical optimization pattern to reduce overhead and improve responsiveness.
**Action:** Use a global `ui` object initialized at the top of the file to cache frequently accessed DOM elements, and replace inline `document.getElementById` and `document.querySelector` calls within loops and rapid-fire event listeners (like click events) with references to this cached object.
