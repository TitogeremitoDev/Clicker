## 2024-03-13 - Cached DOM Queries and Global Scope Anti-pattern
**Learning:** Found a significant performance bottleneck where the `dañocontinuo` game loop (running every 500ms) and high-frequency click events repeatedly executed expensive `document.getElementById` and `document.querySelector` queries. Additionally, the codebase relies on an anti-pattern: using implicit global variables generated from element IDs (e.g. `daño` used instead of `player.caracteristicas.daño`), which can easily cause ReferenceErrors.
**Action:** Created a global `ui` object that caches DOM elements explicitly at the top level and updated loops/event listeners to reference these cached properties, resulting in smoother animations and lower CPU usage for the game loop. Also explicitly fixed the implicit `daño` reference. Always check for global `getElementById` overhead in game loops and avoid relying on implicit globals.
