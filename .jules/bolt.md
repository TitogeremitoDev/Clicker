## 2024-05-15 - Cached DOM Queries on Rapid Events\n**Learning:** In vanilla JS clicker games (like this one), querying the DOM via `getElementById` or `querySelector` on every click or interval tick creates unnecessary overhead and can cause GC pressure or layout thrashing if done frequently enough.\n**Action:** Always cache DOM elements that are queried inside high-frequency event listeners (like rapid clicking) or `setInterval` loops.
