## 2024-05-24 - DOM Caching in Vanilla JS Games
**Learning:** In vanilla HTML/JS games, a very common performance bottleneck is querying the DOM repetitively inside hot paths like click listeners or `setInterval`/`requestAnimationFrame` game loops. Even with simple static elements, this causes noticeable frame drops on frantic user interactions. Furthermore, when writing these optimizations, it's crucial to explicitly add explanatory comments for the optimization as per the "Always do" instruction list.
**Action:** Always extract and cache elements targeted by `document.getElementById` and `document.querySelector` into top-level constants when they are called repeatedly within interval functions or high-frequency event listeners. Always include an explanatory comment labeled as a performance optimization.
