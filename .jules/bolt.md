## 2024-05-24 - DOM Query Caching in Click Handlers\n**Learning:** In a clicker game, DOM elements are accessed extremely frequently (every click + interval). Caching `document.getElementById` and `document.querySelector` calls avoids repetitive DOM traversal, significantly reducing main thread blockages during rapid clicking.\n**Action:** Always cache DOM elements that are accessed in high-frequency event listeners like click handlers in incremental/clicker games.
