## 2024-05-18 - Caching DOM lookups in game loops\n**Learning:** This clicker game queries the DOM repeatedly (every 500ms via `setInterval`) for elements like the health bar and damage counters. Over time, these un-cached lookups severely degrade performance and cause reflows.\n**Action:** When working on tight intervals or click-heavy events in vanilla JS, always extract `document.getElementById` and `document.querySelector` calls to the top-level scope to cache the elements once.
